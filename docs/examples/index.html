Run structure and scope decisions: worked examples

One page per example result in samples/. Prototype for the owner's review of docs/RUN_STRUCTURE_RECORD.md and ROADMAP "Scope decisions for CADET". Generated by tools/build_run_structure_examples.py.

How to read a page

  1. Check these first: places in this run that test a decision.
  2. Levels: operation, phase, section, display step and ISA-88 state on one clock.
  3. Set point vs actual: what the method set, what the pump delivered, what UNICORN measured.
  4. Flow path and volumes, then every fact: stored, derived, hint only, caller gives, not stored.
  5. Scope rows: the ten rows of the roadmap, as they come out on this run.
